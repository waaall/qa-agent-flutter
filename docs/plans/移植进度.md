## 运行命令

```bash
# 安装依赖
cd qa_agent_flutter
flutter pub get

# 生成 freezed 代码
flutter pub run build_runner build --delete-conflicting-outputs

# 运行（各平台）
flutter run -d macos
flutter run -d chrome
flutter run -d ios
flutter run -d android

# 构建
flutter build macos
flutter build web
flutter build ios
flutter build apk
```

---

## 注意事项

1. **首次运行前**必须执行 `flutter pub run build_runner build` 生成 freezed 文件
2. **后端地址**默认为 `http://localhost:5000`，可在设置中修改
3. **STT 服务**默认为 `http://192.168.50.50:9000`，可在设置中修改
4. **会话数据**保存在本地 Hive 数据库，消息从后端加载
5. **主题设置**支持浅色/深色/跟随系统，自动持久化
