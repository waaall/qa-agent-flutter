# Flutter 跨平台重构计划

## 项目目标

将现有 React + TypeScript + Tauri 前端完全重构为 Flutter 应用，支持全平台：
- **移动端**: iOS、Android
- **桌面端**: macOS、Windows、Linux
- **Web 端**: 浏览器

功能与现有设计保持一致（不需要 SSE 流式功能）。

---

## 一、技术栈选型

|---------|-------------|-------------|------|

| 桌面窗口 | Tauri | **window_manager** | ^0.4.x |
| JSON序列化 | TypeScript | **freezed + json_serializable** | latest |
| 录音 | getUserMedia | **record** | ^5.x |
| 音频处理 | Web Audio API | **wav** (自定义编码) | - |

## 四、关键流程实现

### 4.1 聊天流程

```dart
Future<void> sendMessage(String content) async {
  // 1. 添加用户消息
  chatNotifier.addMessage(role: 'user', content: content);

  // 2. 创建助手占位消息
  final assistantMsg = chatNotifier.addMessage(
    role: 'assistant',
    content: '',
    isLoading: true,
  );

  chatNotifier.setLoading(true);

  try {
    // 3. 调用 API
    final response = await chatService.sendMessage(
      query: content,
      sessionId: currentSessionId,
      reset: currentSessionId == null,
    );

    // 4. 更新助手消息
    chatNotifier.updateMessage(assistantMsg.id, (m) => m.copyWith(
      content: response.answer,
      isLoading: false,
      metadata: MessageMetadata(
        queryType: response.queryType,
        enginesUsed: response.enginesUsed,
        confidence: response.confidence,
      ),
    ));

    // 5. 同步会话
    sessionNotifier.syncAfterResponse(response.sessionId, content);

  } catch (e) {
    chatNotifier.updateMessage(assistantMsg.id, (m) => m.copyWith(
      content: '抱歉，处理您的问题时出现错误。',
      isLoading: false,
      error: e.toString(),
    ));
  } finally {
    chatNotifier.setLoading(false);
  }
}
```

### 4.2 会话切换流程

```dart
Future<void> switchSession(String sessionId) async {
  // 1. 设置当前会话
  setCurrentSession(sessionId);

  // 2. 清空消息
  ref.read(chatNotifierProvider.notifier).clearMessages();

  // 3. 加载历史
  final history = await chatService.getSessionHistory(sessionId);
  final messages = history.history.map((h) => Message(
    id: '${sessionId}_${h.timestamp}_${index}',
    role: h.role,
    content: h.content,
    timestamp: h.timestamp,
    metadata: h.additionalKwargs != null
      ? MessageMetadata.fromJson(h.additionalKwargs!)
      : null,
  )).toList();

  ref.read(chatNotifierProvider.notifier).setMessages(messages);

  // 4. 更新访问时间
  updateSession(sessionId, (s) => s.copyWith(
    lastAccessed: DateTime.now().millisecondsSinceEpoch,
  ));
}
```

### 4.3 STT 语音转文字流程

```dart
// stt_notifier.dart
Future<void> startRecording() async {
  state = state.copyWith(state: RecorderState.recording, duration: 0, error: null);

  // 使用 record 包开始录音
  await _audioRecorder.start(
    const RecordConfig(
      encoder: AudioEncoder.wav,
      sampleRate: 16000,
      numChannels: 1,
    ),
    path: _tempFilePath,
  );

  // 启动计时器更新时长
  _startDurationTimer();

  // 自动停止检测（超过 maxDurationMs）
  _startAutoStopTimer();
}

Future<void> stopAndTranscribe() async {
  _stopTimers();
  state = state.copyWith(state: RecorderState.processing);

  // 1. 停止录音
  final path = await _audioRecorder.stop();
  if (path == null) throw Exception('录音失败');

  // 2. 读取音频文件
  final audioFile = File(path);
  final wavData = await audioFile.readAsBytes();

  // 3. 调用 STT 服务转写
  state = state.copyWith(state: RecorderState.transcribing);
  final result = await sttService.transcribe(wavData: wavData);

  // 4. 更新状态
  state = state.copyWith(
    state: RecorderState.success,
    text: result.text,
  );

  // 5. 清理临时文件
  await audioFile.delete();
}
```

```dart
// stt_service.dart
Future<TranscribeResult> transcribe({required Uint8List wavData}) async {
  final formData = FormData.fromMap({
    'file': MultipartFile.fromBytes(wavData, filename: 'audio.wav'),
    'language': _config.language,
    'vad_filter': _config.vadFilter.toString(),
    'word_timestamps': 'true',
  });

  final response = await _dio.post(
    '${_config.baseUrl}${_config.endpoint}',
    data: formData,
  );

  return TranscribeResult.fromJson(response.data);
}
```

```dart
Future<void> uploadDocument(String filePath, String label) async {
  // 1. 调用上传 API
  final response = await documentService.upload(filePath: filePath, label: label);

  // 2. 创建任务
  final task = UnifiedTaskInfo(
    taskId: response.taskId,
    type: TaskType.upload,
    status: TaskStatus.pending,
    progress: 0,
    stage: '等待处理',
    createdAt: DateTime.now().millisecondsSinceEpoch,
    filename: response.filename,
  );
  taskQueueNotifier.addTask(task);

  // 3. 监听轮询状态
  await for (final status in documentService.pollUploadStatus(response.taskId)) {
    taskQueueNotifier.updateTask(response.taskId, (t) => t.copyWith(
      status: _mapStatus(status.status),
      progress: _calculateProgress(status),
      stage: status.stage ?? '处理中',
      errors: status.errors,
    ));

    if (status.status == 'completed' || status.status == 'failed') {
      break;
    }
  }
}
```

```xml
<key>NSMicrophoneUsageDescription</key>
<string>需要麦克风权限以进行语音输入</string>
```

```xml
<key>com.apple.security.device.audio-input</key>
```
